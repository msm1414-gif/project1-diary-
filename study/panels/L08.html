聴覚 II ― 聴覚経路・音源定位・周波数符号化・What/Where

音が基底膜をたわませてから、脳幹の聴覚経路を上行し、一次聴覚野を経て「音源の位置（Where）」と「音の内容（What）」に分かれて処理されるまで（聴覚I 後半）。

1. 音の伝達と基底膜

音波 → 鼓膜 → ツチ骨 → キヌタ骨 → アブミ骨 → 卵円窓 → 蝸牛リンパ液 → 基底膜がたわむ
  • 周波数に応じて基底膜の特定の場所が振動する（＝のちの「場所符号化」の基盤）。
  • 正円窓は振動を逃がす圧力の逃げ道。

2. 聴覚経路 ― 末梢から一次聴覚野まで

聴神経(蝸牛神経) → 蝸牛神経核 → 上オリーブ複合体(延髄) → 下丘(中脳) → 内側膝状体(視床) → 聴覚皮質
段階構造補足
末梢聴神経（蝸牛神経）延髄へ投射
延髄蝸牛神経核（腹側／背側）→ 上オリーブ複合体台形体・外側毛帯を経由
中脳下丘（Inferior colliculus）
視床内側膝状体（MGN）視覚のLGNに対応
皮質聴覚皮質外側溝の下壁部

3. 音源定位① 両耳間の位相差（時間差）

水平方向（左右）の音源位置は、左右の耳に届くタイミングのズレ（両耳間時間差 ITD＝位相差）から推論する。

状況両耳への到来
前方 or 後方両耳に同時到来（左右差なし）
左方左耳が先に到来
右方右耳が先に到来
注意前後の区別（同時到来同士）はこの機構だけでは曖昧 → 頭部の動きや耳介の効果が補助する。

4. 同時検出器（coincidence detector）モデル

中核左右からの信号が同時に届いたときにだけ興奮する神経細胞を並べ、左右の軸索を遅延線（delay line）として使うことで音源位置を符号化する。
  • 左右の発火がちょうど出会った場所の細胞体が出力する。
    • 両耳同時到来 → 中央の細胞体が発火。
    • 左耳が先 → 右寄りの細胞体が発火。
    • 右耳が先 → 左寄りの細胞体が発火。
  • どの細胞体が発火したか＝左右の音源位置の符号化を担う。

同時検出器の在処

  • 上オリーブ複合体に存在する（延髄レベル）。
  • メンフクロウで実証（Carr & Konishi, 1988）。鳥類の層状核（Nucleus laminaris）はヒトの上オリーブ核と相同で、両側（同側・反対側）から入力を受ける。

5. 周波数の符号化① 場所符号（Place code）

  • 音の周波数は、基底膜のどの場所が最もたわむかで符号化される。
  • アブミ骨に近い（蝸牛基部）＝高周波数／遠い（蝸牛頂部＝Apex）＝低周波数。
  • この場所による符号化は一次聴覚野まで続く周波数表現として保持される。

6. 周波数の符号化② 場所符号と頻度符号（rate code）＜発展＞

場所符号が低周波で不利な理由

  • 低周波数は Apex（蝸牛頂部） に対応するが、解像度に不利な物理構造。
  • 200Hz/100Hz の比も 20000Hz/10000Hz の比も物理的に約 3.5mm に広がる → 低周波側は場所で解像しにくい。

頻度符号（rate code）

  • 聴神経が1秒間に何回発火（パルス）したかで周波数を表す。進行波の到来のたびに Apex の有毛細胞が発火。
  • 40回＝40Hz なら観察可能だが、10kHz は観察不可能 → 高周波はplace codeが担当。
周波数音の高さの知覚音の大きさの知覚
高周波数場所符号化（特定場所の有毛細胞が発火）活動電位の頻度
中周波数場所符号化（同上）活動電位の頻度
低周波数頻度符号化（頂部の有毛細胞が音波に同期して発火）活動する有毛細胞の数

7. 周波数再現地図（Tonotopic representation）

  • 基底膜の場所（周波数）の特性は皮質まで秩序立てて保持される＝周波数再現地図（tonotopy）。
  • サル一次聴覚野で、蝸牛基部（高周波）〜頂部（低周波）に対応する勾配が観察される（Petkov et al., 2006）。

8. A1以降の階層構造 ― Core / Belt / Parabelt

領域特徴
Core（核）A1を含む。視床MGNから高密度に直接入力。時間応答が速く一瞬の音の変化・正確な時間情報を捉える。純音に応答。
Belt（周縁野）周波数分解された音の特徴を計算。純音に応答しにくく複合音（音声）に応答。左右両耳差の計算＝音源定位情報。
Parabeltより高次の聴覚的表象・他感覚（視覚）との統合か（不確か）。
Core(A1) ⇄ R ⇄ RT → Belt → Parabelt（＋高次からのフィードバック）

9. What / Where の二重経路（聴覚版）

経路Belt起点方向役割投射先
What（前方）AL（前外側）前→腹側→前頭声の種類・音の内容PB→STS・TE野(IT)→PFC
Where（後方）CL（尾外側）尾側→頭頂→前頭音源の場所PP(後頭頂)→PFC
  • AL（前方）＝声の種類に選択的（MCPI: Monkey call preference index が高い）。
  • CL（後方）＝音源位置。Half width（半値幅）が小さいほど正面向きにだけ応答＝空間チューニングが鋭い。
  • 音声実験：AL細胞は全帯域の音声によく反応し、2kHz以下のみ／以上のみに削ると反応が消える → 複数帯域の統合で音声を符号化。

10. 視覚との対応づけ

  • 後方（Caudal）経路＝視覚の Where 経路（背側・頭頂）と統合。
  • 前方（Anterior）経路＝視覚の What 経路と IT/STG で統合。
  • 統合の要：STG / STS / TE（多感覚統合・物体認知・意味の完成）。

11. ヒトでの計測 ― What/Where と半球差

  • 課題：内容判断ブロック（イヌ→フルート→咳…）と位置判断ブロック（右→左→右…）。「同じ音／同じ方位が2回続いたら回答」。
  • 結果（Alain et al., 2008）：左半球＝What、右半球＝Whereの機能差。
まとめ一次聴覚野から 尾側→右背側経路（音の位置＝Where）、前→左腹側経路（音の内容＝What）。

12. 声への選択性 ― TVA（側頭声領域）

  • ヒトに VOC（音声） と周波数マッチさせた NOVOC（非音声） を聞かせ引き算 → 上側頭回前部（聴覚野の前）が声に反応（Belin et al., 2000, 2004）。
  • TVA（Temporal Voice Area 側頭声領域）：ヒトはヒトの声、サルはサルの声に強く反応（同種の声への選択性）。
  • 表現類似性分析（RSA）：多様な音（ヒト声・マカク声・非音声など）の脳活動パターンの「似ている度合い」を計算し、同類か別物かを表現。

13. まとめと未解決問題

全体像音の伝達 → 場所／頻度による周波数符号化 → 音源定位（位相差・同時検出器）→ Core/Belt/Parabelt の階層 → What(前)/Where(後) 経路 → 声への選択性。
  • 講師の見解：聴覚処理の本体は物体認識（What）そのものより、混合された時系列信号の分離・推論（信号分離）の計算にあるのではないか。音源が分離できて初めて位置と属性まで解析できる（＝視覚に比べ未解明の問題が山積）。
