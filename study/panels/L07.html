聴覚 I ― 音とは何か・耳による音の符号化

空気の粗密波である音が、鼓膜・耳小骨・蝸牛を経て有毛細胞で電気信号に変換され、聴神経へ伝わるまで。

1. 音とは何か ― 空気の粗密波

  • 音とは空気の粗密波（縦波 / longitudinal wave）。空気分子の密度が疎と密を繰り返しながら伝わる。
  • 波形として描くと横波（正弦波）で表現できる。
  • 音の物理量は時間次元とともにある（時間変化する信号）。

2. 音の物理的要素（音の3要素）★重要

3. ヒトの聴覚器官の全体像

外耳（耳介・外耳道・鼓膜） → 中耳（ツチ骨→キヌタ骨→アブミ骨） → 内耳（蝸牛・聴神経）
  • 外耳：耳介 → 外耳道 → 鼓膜（Tympanic Membrane）
  • 中耳：耳小骨＝ツチ骨(Malleus)→キヌタ骨(Incus)→アブミ骨(Stapes)、エウスタキー管
  • 内耳：蝸牛（Cochlea）・三半規管・前庭神経・聴神経（蝸牛神経）。アブミ骨は卵円窓を介して蝸牛へ、正円窓（Round Window）が圧を逃がす。

4. 音の伝播（概略）★重要

音が到来 → 耳小骨で振幅の増幅 → 蝸牛のリンパ液へ振動伝達 → 神経発火 → 聴神経へ電気信号
  • 鼓膜での空気振動の受容 → 耳小骨（テコの原理）による圧力増幅 → 蝸牛リンパ液中の波形成。
  • 小さな振動も、分析しやすい大きな振幅に変換される。

5. 蝸牛の構造とコルチ器

コルチ器内耳の蝸牛にある、音を感じ取る中心的な器官。リンパ液の振動を電気信号に変換し脳へ伝送する。

蝸牛断面の主な構造：蝸牛骨壁・前庭階(Scala vestibuli)・蝸牛管(Cochlear duct)・蓋膜(Tectorial membrane)・基底膜(Basilar membrane)・鼓室階(Scala tympani)・らせん神経節。

6. 基底膜の構造と進行波 ★最重要

基底膜は蝸牛内を走る膜。伸ばして観察すると場所で性質が変わる。アブミ骨で生成された振動がリンパ液へ伝わると基底膜は「たわみ」、進行波(travelling wave)が生成される。

場所幅・厚み揺れ方担当周波数
アブミ骨側
Base		薄く幅が狭い小さなエネルギーで揺れる高周波
蝸牛頂側
Apex(Helicotrema)		厚く幅が広い大きなエネルギーで揺れる低周波
トノトピー基底膜で担当する「周波数」が決定される。基底膜に近い(Base)＝高周波数／遠い(Apex)＝低周波。この周波数と場所の対応をトノトピー(tonotopy)という。

紐・むちのアナロジー

近くは太く遠くは細い紐をたわませる（むちをしならせる）と、どこかで振幅が最大となり、それ以降はエネルギーを消失する。高周波は Base 近く、低周波は Apex 近くでピークをつくる。

物理実験人工蝸牛の物理実験で、周波数によって基底膜の変位場所が決まることが確認された(25→50→100→150Hzと高周波ほどBase近くへ)。進行波の研究でベケシー(von Békésy)がノーベル賞を受賞。

7. コルチ器と有毛細胞 ★重要

基底膜の変位が伝わる → 振動によってコルチ器の細胞が変位・興奮する。基底膜が「押される」と有毛細胞の線毛がたわむ。

8. 線毛と機械電気変換（MET）★頻出

  • 隣り合う線毛はティップリンク(Tip link, cadherin 23)でつながる。
  • ティップリンクはイオンチャネル(MET channel, TRPA1)につながり、主にカルシウムイオン Ca²⁺の流入を調整する。
  • 静止電位はマイナス（通常状態）。

符号化線毛のたわみ量（＝基底膜の変位の大きさ）に応じて聴神経の発火頻度が変わる（低頻度 ↔ 高頻度）。
