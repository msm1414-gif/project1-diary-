## 第2回 導入・序論

1. 認知脳科学を構成する3つの学問と、それぞれの歴史的由来は？
   → **心理学（人文学・哲学）／脳科学（生理学・神経科学・生物学）／認知科学（計算機科学・情報学）**

2. 「一元論」と「二元論」の違いは？
   → 一元論＝**こころは脳（身体）が作り出す**／二元論＝**こころと脳は別物**

3. デカルトが心と身体の相互作用の場と考えた脳の部位は？
   → **松果体**

4. 「動物には心が介在しない」というデカルトの考えを何と呼ぶか？
   → **動物機械論**

5. 認知科学の計算機アナロジーで、固定記憶・作業記憶・中央実行系はそれぞれ何に対応するか？
   → **HDD/SSD ／ RAM（メモリー） ／ CPU**

6. 感覚貯蔵庫→短期貯蔵庫→長期貯蔵庫と考えるモデルとその提唱者は？
   → **二重貯蔵モデル（Atkinson & Shiffrin, 1968）**

7. ワーキングメモリの古典モデルの構成要素を挙げよ。
   → **中央実行系・視空間スケッチパッド・エピソードバッファ・音韻ループ**（Baddeley & Hitch, 1974 / Baddeley, 2000）

8. 脳の部分的切除の研究で知られる、失語症研究の人物は？
   → **Paul Broca（1824–1880）**

9. ヒト・コウモリ・クジラ・イヌの前肢のように「形は違うが由来が同じ」構造を何と呼ぶか？
   → **相同（そうどう）**

10. 霊長類の主な特徴を4つ挙げよ。
    → **樹上への適応／手指の把握力（平爪）／眼窩軸の収斂による立体視／色覚の再獲得**（＋嗅覚の退行）

11. 初期霊長類の進化はおよそ何年前から始まったか？
    → **約6500万年前（65 Mya）**

12. 現生人類の学名は？また過去に存在し絶滅した人類を何と呼ぶか？
    → **Homo sapiens ／ 化石人類**

13. Homo属の脳拡大の「機能的説明」として有名な説は？
    → **社会認知の説**

## 第4回 視覚 I

14. 「感覚」と「知覚」の違いは？
    → 感覚＝**神経系の細胞活動を介した物理的過程**／知覚＝**意識にのぼる、感覚情報の解釈を伴う過程（中枢神経系ニューロンが必要）**

15. ヒトが受容できる可視光の波長範囲は？
    → **380〜760 nm**

16. 光の色の3次元（HSV）とは？
    → **色相（Hue＝波長）／彩度（Saturation＝純粋さ）／明度（Value＝強さ）**

17. 網膜で視細胞がない、盲点にあたる部位の名称は？
    → **視神経円盤（optic disk）**

18. 網膜の中心にあたる、視力が最も高い部位は？
    → **中心窩（fovea）**

19. 桿体（Rod）と錐体（Cone）の機能的違いは？
    → 桿体＝**暗所で機能・高感度・色を識別しない（白黒）・中心窩にない**／錐体＝**明所で機能・色を識別・中心窩にある**

20. 錐体の3タイプと対応する色は？
    → **S錐体＝青（短波長）／M錐体＝緑（中波長）／L錐体＝赤（長波長）**

21. 水平細胞が担う、コントラストを高める働きを何というか？
    → **側抑制**

22. 光が当たったとき、視細胞の膜電位はどうなるか？（伝達物質は？）
    → **過分極（膜電位が下がる）。グルタメートの放出が減る**

23. 神経節細胞で光情報が「脳へ」伝わるとき発生するものは？
    → **活動電位**

24. 「あるニューロンが網膜のどの範囲に反応するか」を表す概念は？
    → **受容野（receptive field）**

25. 中心視と周辺視で視力が違う理由を受容野の観点で説明せよ。
    → **中心視は受容野が狭く視力が高い／周辺視は受容野が広く視力が低い**

26. 視覚経路（visual pathway）を順に並べよ。
    → **視神経 → 視交叉 → 外側膝状体(LGN) → 一次視覚野(V1) → 高次視覚野**

27. 視交叉で交叉するのは網膜の内側（鼻側）か外側（耳側）か？
    → **内側（鼻側）が交叉して反対側へ。外側（耳側）は交叉せず同側へ**

28. 瞳孔の対光反射に関わる経路は？
    → **視蓋前野経路**

29. サーカディアンリズムの調整に関わる経路は？
    → **視床下部経路**

30. LGNの大細胞系・小細胞系・顆粒細胞系のうち、色情報を持たないのはどれか？
    → **大細胞系**（小細胞系＝赤緑、顆粒細胞系＝青）

31. 大細胞系と小細胞系の空間解像度・時間解像度の特徴は？
    → **大細胞系＝空間低・時間高（一過性）／小細胞系＝空間高・時間低（持続性）**

32. V1のブロブ（blob）は何に感受性を持つか？
    → **色**（インターブロブは方位・動き・空間周波数・両眼視差）

33. 背側経路と腹側経路が担う認識は？
    → **背側＝Where（位置・動き）／腹側＝What（形・色・大きさ・テクスチャ）**

34. ON型神経節細胞の反応の仕方は？
    → **受容野中心部の光で興奮／周辺部の光で抑制**

35. 「境界で明暗・色が強調されて見える」現象の原因となる仕組みは？
    → **側抑制（境界ではON領域の発火に対し周辺OFF抑制が小さく、興奮が増大する）**

36. 色覚は「視細胞」と「神経節細胞以降」でそれぞれ何説で説明されるか？
    → **視細胞＝3原色説／神経節細胞以降＝反対色説**

37. 反対色の3つのペアは？
    → **赤↔緑・青↔黄・白↔黒**

38. 「Coneにない黄が原色に感じる」のはなぜか？
    → **黄を初期段階（神経節細胞レベル）で定義・計算しているため**

39. 負の残像（negative afterimage）で見えるのは？またその原因は？
    → **補色が見える。網膜神経節細胞の発火頻度の順応（長時間興奮→リバウンドで抑制）によるバランスの崩れ**

40. 色の波長情報を高次に伝えるのは大細胞系か、小細胞系・顆粒細胞系か？
    → **小細胞系・顆粒細胞系**（大細胞系は色情報を渡さない）
